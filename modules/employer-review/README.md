# Employer Review

**Owns:** the employer-facing view of a consented passport, reviewer action
(no action / interview / shortlist / hire / development) and reviewer feedback.
**Does not own:** unconsented evidence.

Reserved — not built yet. Employer access is only ever through a passport
snapshot, never direct access to raw student tables (ASCEND-ENG-015 §7.2), and
stops immediately when consent expires or is revoked.
