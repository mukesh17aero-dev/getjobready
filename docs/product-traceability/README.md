# Product traceability — reserved

The chain every feature must trace through (ASCEND-ENG-015 §15.1):

company thesis → MVP hypothesis → target-user problem → journey step →
feature → event → metric → decision threshold → gate decision

A feature is not approved merely because it can be built: it must trace to a
risky assumption, generate observable behaviour, and support a decision to
continue, change, narrow or stop. Risky assumptions and their evidence are
tabled in §15.1; metric targets in §15.3.
